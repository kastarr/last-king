# TechXTRA candidate portal preview

Static, no-backend preview for the TechXTRA candidate journey.

- Routes: `/techxtra/`, `/techxtra/applied/`, `/techxtra/signin/`, `/techxtra/assessment/`
- No authentication, application submission, personal-data collection, timer, or assessment submission is implemented.
- No demo credentials or invented assessment duration are included.
- Pages are marked `noindex,nofollow` and receive `X-Robots-Tag: noindex, nofollow`.
- This preview must not be represented as a live recruitment portal until official job details, application handling, authentication, and assessment requirements are supplied and integrated.
